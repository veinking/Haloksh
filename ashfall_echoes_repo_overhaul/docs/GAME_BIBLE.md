# Ashfall: Echoes of the Hollow — Game Bible

## High Concept

Ashfall is a dark fantasy roguelike deckbuilding RPG where the player is a dead pilgrim carrying a lantern heart through a cursed world of bells, ash, roots, and stolen memories.

The presentation should feel like a grim pixel-art/HD-2D-inspired RPG world, but the gameplay core should be a strategic deckbuilder like Slay the Spire.

## Core Pillars

1. **Combat is the game.**
   Traversal is atmosphere and route presentation, not the main mechanical challenge.

2. **Every card is a memory.**
   Cards represent attacks, instincts, wounds, prayers, bargains, and half-remembered sins.

3. **Every relic is a bargain.**
   Relics should feel exciting, but many should carry costs or route consequences.

4. **Bosses are failed philosophies.**
   Each boss should represent a corrupted solution to suffering:
   - Bell Mother: silence as mercy
   - Saint Cinder: purification as violence
   - Faceless King: identity control as safety
   - Hollow Tree: comfort as imprisonment
   - First Bell: the original wound

5. **The first win is a lie.**
   The first clear gives the Ash Lie ending. It feels satisfying, then reveals the real game.

6. **Death leaves a memory.**
   Death should preserve one card or unlock a future grave event so no run feels wasted.

## Target Feel

- Easy to understand in 5 minutes
- Hard to master after 50 hours
- Dark, readable, tactile, satisfying
- Mobile-friendly but premium, not cheap mobile monetization

## Launch Content Target

- 5 regions
- 90+ cards
- 75+ relics
- 5+ weapons
- 14 regular enemies
- 7 elites
- 5 minibosses
- 4 main bosses
- false ending plus true endings
- codex, run history, death memory, unlock tracker

## Current Prototype Focus

Current repo only covers Bellgrave Parish and the Bell Mother false ending path. Expand from here using data-driven systems.
